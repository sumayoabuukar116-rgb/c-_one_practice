C# Practice – Assignment 1

Student Information

This assignment is a C# Windows Forms application that uses the Parse method to process a Student ID and display student information.

Features

1. Show Information Button

The Show Information button reads the Student ID entered by the user, uses the Parse method to process the required information, and displays the student information in the labels.

2. Clear Button

The Clear button clears the information entered in the TextBoxes and removes the displayed student information from the labels.

3. Exit Button

The Exit button closes the application.

How It Works

1. The user enters a Student ID.
2. The user clicks Show Information.
3. The program processes the Student ID using the Parse method.
4. The student information is displayed on the form.
5. The Clear button can be used to clear the information.
6. The Exit button closes the application.

Technologies Used

- C#
- Windows Forms
- Visual Studio
- Parse Method
